# Support

`conpty-oxide` is maintained on a best-effort basis without a response-time or
fix-time service-level agreement.

## Getting help

- Read the [API documentation](https://docs.rs/conpty-oxide), the
  [examples](https://github.com/P4suta/conpty-oxide/tree/main/examples), and
  [ConPTY pitfalls](https://github.com/P4suta/conpty-oxide/blob/main/docs/conpty-pitfalls.md)
  first. Most hangs, missing output, and "the child never exits" reports are
  one of the documented pitfalls.
- Use the question issue form for usage questions and the bug form for a
  reproducible defect.
- Include the crate version or commit, the output of `winver`, the
  architecture, the Rust version, which feature flags are enabled, and a
  minimal reproduction.

Do not include secrets, terminal transcripts containing private data, or
suspected vulnerability details in a public issue. Report security concerns
through
[GitHub private vulnerability reporting](https://github.com/P4suta/conpty-oxide/security/advisories/new).

Commercial support and private implementation consulting are not offered by
this repository.
